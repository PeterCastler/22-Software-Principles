# Source note: UNIX Time-Sharing System Foreword

- Authors: M. Douglas McIlroy, E. N. Pinson, and B. A. Tague
- Publication: *Bell System Technical Journal*, 1978
- URL: https://www.textbookoflinux.com/references/mcilroy1978.html
- Accessed: 2026-07-15
- Type: primary historical statement, summarized here

The foreword's maxims emphasize programs that do one job well, outputs usable as inputs to unknown programs, early working software, willingness to rebuild clumsy parts, and tools that leverage effort. The philosophy's minimalism comes from focused responsibilities plus cheap composition, not from isolated tiny programs.

Simple, stable interfaces allow small tools to solve larger problems without absorbing every use case as a feature.
