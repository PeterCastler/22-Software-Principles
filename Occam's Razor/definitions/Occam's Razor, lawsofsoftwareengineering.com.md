# Source note: Occam's Razor

- Author: Milan Milanović
- URL: https://lawsofsoftwareengineering.com/laws/occams-razor/
- Accessed: 2026-07-15
- Type: software-engineering interpretation

Among adequate competing explanations or solutions, prefer the one that introduces fewer unsupported assumptions and unnecessary entities. In software this means fewer unjustified services, databases, integration points, and speculative mechanisms—not blindly choosing the shortest program.

The source uses a monolith versus unnecessary microservices as an architectural example and simple causes before exotic ones as a diagnostic example.
