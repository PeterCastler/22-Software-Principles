# DRY ↔ Convention over Configuration

Assessment status: Final publish; validated for freeze  
Primary classification: Reinforcement  
Secondary classifications: None  
Evidence grade: Convergent  
Confidence: high

## Shared decision surface

Causally connected decisions: DRY governs authority for changing knowledge; Convention over Configuration governs routine defaults versus explicit exceptions.

## Interaction mechanism

A convention makes one shared default authoritative instead of duplicating the same routine choice in many configuration files.

## Material consequence

Repeated configuration is removed and exceptional values remain explicit at their point of ownership.

## Context in which it applies

Applies when many instances restate the same non-domain choice.

## Counterexample or boundary

Different regulatory settings are independent policy and should not be collapsed into a naming convention.

## Worked example

**Starting condition:** A convention makes one shared default authoritative instead of duplicating the same routine choice in many configuration files.

**Decision after applying both principles:** Repeated configuration is removed and exceptional values remain explicit at their point of ownership.

**Boundary check:** Different regulatory settings are independent policy and should not be collapsed into a naming convention.
