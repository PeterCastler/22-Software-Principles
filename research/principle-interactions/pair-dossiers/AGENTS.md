# Purpose

- Maintain the published pair-level analyses that justify accepted, bounded, or adjudicated principle interactions.

# Ownership

- Each `P###-*.md` file owns one stable pair ID and the evidence-backed relationship between its named principles.
- This document owns the common dossier structure and folder-wide consistency rules.

# Local Contracts

- Keep the filename ID, title principles, screening row, disposition, and journal references consistent.
- Retain the shared decision surface, mechanism, material consequence, applicable context, counterexample, resolution procedure, combined instruction, evidence, independent review, and journal references.
- State context limits directly; do not generalize a project-specific interaction into a universal rule.

# Work Guidance

- Use the canonical profiles as the baseline meaning of each principle.
- Prefer operational consequences and falsifiable boundaries over thematic similarity.
- Reconcile dossier changes with the screening datasets and research decision trail.

# Verification

- Verify the dossier’s pair ID and path against `../pair-screening.csv` and `../independent-screening.csv`.
- Run the parent integrity checks when a dossier change also updates a covered dataset, profile, or chapter.
