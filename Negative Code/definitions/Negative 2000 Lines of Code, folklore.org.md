# Source note: -2000 Lines of Code

- Author: Andy Hertzfeld
- Subject: Bill Atkinson and the Lisa team, February 1982
- URL: https://www.folklore.org/Negative_2000_Lines_Of_Code.html
- Accessed: 2026-07-15
- Type: primary-team historical account

Managers asked engineers to report lines written. After Atkinson replaced QuickDraw's region engine with a simpler, more general algorithm, it ran about six times faster and used roughly 2,000 fewer lines. He reported “-2000,” exposing why added line count is a perverse productivity measure.

The lesson is not that deletion alone is valuable; the rewrite improved behavior and reduced implementation. Progress is capability, clarity, and performance per maintenance obligation.
